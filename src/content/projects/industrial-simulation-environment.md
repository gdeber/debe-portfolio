I designed and implemented a virtual test environment for industrial plant operations. It integrated Siemens PLCSIM with open-source tools and virtualization using VMware and Proxmox.

The environment made it possible to test production-line behavior before commissioning, drastically reducing test time and reliance on physical hardware.
